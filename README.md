# 中文排版(zhtypo)

**它是一支荧光笔,不是自动修改器。** 装上就在编辑器里画波浪线,一个字都不动 —— 改不改你说了算。

中英之间该有的那个空格、中文句子里混进来的半角逗号、重复词、标题 `#` 后缺的空格、行尾多余空格 ——
这些问题过去只在**发布那一刻**才被发现(`wechat-publisher` 管剥样式,不管文字质量),那时全篇几百处已无从改起。
本插件把发现的时刻提前到**你打字的当下**。

## 功能

| 层次 | 怎么用 |
|---|---|
| **写的时候(零操作)** | 命中处画波浪线。点一下弹小浮层:**修正 / 忽略这一处 / 关掉这条规则**,点哪个都算数,不点什么也不会发生 |
| **写完一段** | 命令面板「中文排版:修当前段落」—— 光标那一段里可自动修正的一次修完,**一个事务 = 一次 Cmd+Z 全撤销** |
| **发出去之前** | 命令面板「中文排版:体检当前笔记」,或点状态栏的「排版 N」→ 体检报告:按规则分组,每条给「第 N 行第 M 列」与上下文,点一行跳过去,或「一键全修」 |

### 六条规则(设置页逐条开关)

1. **盘古之白** —— CJK 与半角字母/数字之间加空格(照 pangu.js 的口径)
2. **标点混用** —— 中文句子里的 `,` `.` `!` `?` `:` `;` 提示换全角(反之亦然)
3. **引号不一致** —— 同篇里「」与“”混用时提示统一(**只提示,默认不自动改** —— 这是风格选择,不是错误)
4. **重复词** —— 「的的」「是是」这类相邻重复
5. **标题缺空格** —— `#标题` → `# 标题`
6. **行尾多余空格** —— markdown 的两空格换行会豁免

另有两个旋钮:「单个 `#` 也当标题」(**默认关**,因为它和 `#标签` 长得一样)、「单段字数上限」(超过就跳过不查,免得长文掉帧)。

## 哪些地方它一个字都不碰

代码围栏(``` 与 ~~~,含未闭合)、行内代码、`$公式$` / `$$公式$$`、URL、`[显示](路径)` 的路径部分、
`[[wikilink]]`、HTML 标签与注释、frontmatter —— **全部豁免**。三层豁免并联:只要有一层说豁免就豁免。

> 设计取向写在这里:**宁可少提示一百次,不可错改一次。** 在代码块里给你的代码插一个空格,
> 比漏掉一百个该加空格的地方坏得多。

## 数据在哪

- **不写你的笔记文件** —— 所有改动走编辑器事务(不做「读全文 → 改 → 整篇写回」那条毁数据路径),全部进笔记自己的撤销栈。
- **纯本地** —— 规则全部写死在代码里,不联网、不调 AI、不枚举全库,你的文字不出这台机器。
- **唯一会落盘的**:你主动点「导出报告」时产生的两份,落在 `<工作文件夹>/排版体检/` 下 ——
  `<笔记名>_<时间戳>.md`(人看的)与同名点开头的 `.json`(机器数据)。
  **同名绝不覆写**,自动加 `-2`…`-9`;报告正开在编辑器里时会直接拒绝导出。

## 范围说明:明确不做什么

1. **不做错别字 / 语法检查** —— 那要词典与模型,是另一个量级。
2. **不做全库批量修** —— 批量改文件是 `vault-gardener`(库园丁)的地盘;本插件只管当前编辑器里这一篇。
3. **不做自动修** —— 默认只画线,改动一律由你触发。
4. **不抢任何按键** —— 编辑器扩展跑在 `normal` 桶,纯装饰;中文输入法组合中(`view.composing`)绝不介入。
5. **不联网、不调 AI、不要第二个 key**。

## 与其它插件的边界

- ↔ `vault-gardener`:园丁扫全库出提案改文件;zhtypo 只管当前这一篇的编辑器内。
- ↔ `wechat-publisher`:发布器管剥样式与平台体检;zhtypo 管文字本身。

## 已知取舍

- 贡献点的标题(命令面板 / 视图名 / 设置项标签)是**注册时**的单字符串,宿主不做运行时重解析 ——
  切换界面语言后这些宿主面要等重启才跟上。视图内的一切文案是实时跟随的。
- 命令 id `zhtypo-check` 是历史 id,语义是「修当前段落」。

## 兼容

`apiVersion 1`。旧宿主缺 `registerEditorExtension` / `registerStatusItem` / `notify` 时优雅降级(藏掉对应入口),不会让 setup 抛错。

## 自检

```bash
node check.mjs
```
